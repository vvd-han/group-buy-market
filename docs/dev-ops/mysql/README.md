# 拼团数据库

空库由 MySQL 8 的初始化目录依次执行建表脚本和开发样例。样例包含同一个商品在两个渠道的原价、活动和测试标签。Docker 仅在空数据目录执行初始化脚本。

旧库先执行 [建表脚本](sql/group_buy_market.sql)，再执行 [投放回填](migrations/261120_backfill_channel_activities.sql)。回填保留已配置的投放，列出重复组合和缺少的渠道商品。重复组合需要确认实际投放活动。缺失商品从商品目录补齐真实名称和原价。已有手工建表的环境需确认投放和 SKU 的三字段唯一约束、标签明细的两字段唯一约束和标签批次的唯一约束，并按建表脚本核对标识字段使用的二进制排序规则。开发样例用于空库。

标签资格从 MySQL 的 `crowd_tags_detail` 精确读取。手工导入批次使用 `tag_type=2`、`status=1`，在 `tag_rule` 填写逗号分隔的用户 ID。批次完成后状态为 `3`。参与量和消费金额类规则依赖交易数据。
